## 3. 具体加了什么

### 3.1 仪表条（顶栏下方一条）

`● SYS ONLINE │ MODULE 01 · 系统概览 │ PANELS 9 │ RECORDS 4 │ ‹刻度尺› │ 09:54:26`

- 随页签切换自动更新模块号 / 标题 / 面板数 / 记录数
- 右侧时钟每秒走动（页面里唯一持续运动的元素，且只是一行小字）
- 模块号与页签一一对应（系统概览 01 … 系统设置 08）

### 3.2 卡片 = 仪表面板

- 四角括号 + 顶部高光 + 1px 发丝描边
- 右上角**角标序号**：`01-03`（页签号-卡片号），一眼可定位
- 含图表的卡片额外在**底边画测量刻度尺**
- 悬停：描边点亮 + 上浮 2px + 跟随光标的径向聚光

### 3.3 侧边导航

- 悬停时左侧滑出 2px 青色指示条
- 当前页签带内发光

### 3.4 表格

- 表头改等宽字 + 字距 + 底部发丝线
- 行悬停：淡青底 + 左侧 2px 强调条

### 3.5 动效清单（全部为局部或一次性）

| 动效 | 触发 | 范围 |
|---|---|---|
| 卡片入场揭示 | 首次进入页签 | 卡片级，带交错延迟，一次性 |
| 数字滚动 | 首次进入页签 | 统计卡内数字，约 900ms 一次 |
| 卡片聚光 + 上浮 | 鼠标悬停 | 单张卡片内 |
| 侧栏指示条滑入 | 鼠标悬停 | 单个导航项 |
| 按钮流光 | 鼠标悬停 | 单个按钮 |
| 表格行高亮 | 鼠标悬停 | 单行 |
| 页签切换淡入 | 重复进入同一页签 | 页面级 300ms，一次性 |
| 顶栏时钟 | 常驻 | 一行小字 |

> **没有**横穿整屏的移动色带、全屏覆盖层、持续闪烁。

## 4. 性能红线（实测踩坑，务必保留）

第一版上线后**页面直接卡死**（浏览器弹「此页面没有响应」）。定位到三个原因，已全部修掉并在代码里留了注释：

| 原因 | 为什么致命 | 处理 |
|---|---|---|
| `background-attachment: fixed` | body 上多层固定背景 + 内部滚动容器 ⇒ 持续整屏重绘 | 删除 |
| `header` 上的 `backdrop-filter: blur()` | 与滚动容器、大面积背景叠加产生持续昂贵合成 | 删除，改纯色半透明 |
| CSS `:has(canvas)` | 每次 DOM 变化都要全文档重算匹配；数字滚动每帧改文本 ⇒ 主线程打满 | 改为 JS 打 `.cx-chart` 类 |
| MutationObserver + 在回调里改同一个类名 | 观察器回环，无限触发 | 加 `activating` 重入守卫 |

另外把卡片聚光从「每张卡挂一个 mousemove」改成**单个委托监听**（30+ 张卡）。

**结论**：这类重型 SPA 看板上，CSS 选择器与合成属性的性能代价远高于 JS；`:has()`、`background-attachment:fixed`、`backdrop-filter` 三者都属于"看起来无害、实际致命"。

## 5. 验证方式与局限

- **无头浏览器**（`--virtual-time-budget`）渲染正常，但**验证不出卡死**——虚拟时间下 rAF 与合成路径被简化，两次无头渲染都正常，问题只在真实浏览器复现
- 真实浏览器复核确认：数字滚动落到正确终值（156 / 89 / 87.3% / 7）、顶栏时钟走动、页签切换后仪表条与卡片序号同步更新、图表正常渲染
- 卡死类问题**必须用真实浏览器验证**，不能只看无头截图
