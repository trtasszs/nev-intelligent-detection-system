# 车小智 · 后端 API + 智能对话

给 `车小智.html` 配的后端接口与对话模块。**零第三方依赖**，只用 Python 标准库。

- 页面：`E:\！！！高职比赛\车小智.html`
- 后端：`E:\！！！高职比赛\车小智-后端\`
- 原始页面备份：`E:\！！！高职比赛\车小智.html.bak-<时间戳>`

---

## 1. 快速开始

### 方式一：双击启动（推荐）
双击 **`启动车小智服务.bat`**，它会自动寻找可用的 Python（依次尝试 `py -3` → `python` → 本机 DSH 自带运行时），
启动服务并自动打开浏览器。

### 方式二：命令行
```bat
cd /d "E:\！！！高职比赛\车小智-后端"
python server.py --port 8000 --open
```

启动后访问 **http://127.0.0.1:8000/** 。

> 也可以直接双击 `车小智.html`（file:// 方式）打开：页面会自动去连 `http://127.0.0.1:8000` 的后端，
> 连不上就自动退回页面内置的离线知识库，功能不中断。

### 参数
| 参数 | 说明 | 默认 |
|---|---|---|
| `--host` | 监听地址 | `127.0.0.1` |
| `--port` | 端口 | `8000` |
| `--open` | 启动后自动打开浏览器 | 关闭 |

## 3. 接口文档

所有接口统一返回 JSON，均带 `ok` 字段；已开启 CORS（`Access-Control-Allow-Origin: *`），
因此 `file://` 直接打开的页面也能调用。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/` | 返回 `车小智.html` |
| GET | `/assets/*` | 静态资源（限定在该目录内，防路径穿越） |
| GET | `/api/health` | 健康检查：版本、当前模式、知识库条目数 |
| GET | `/api/config` | 读取配置（`api_key` 自动打码） |
| POST | `/api/config` | 保存配置（可在线填 API Key，无需改文件） |
| GET | `/api/knowledge` | 离线知识库覆盖范围 |
| POST | `/api/diagnose` | 故障诊断，返回结构化结果 |
| POST | `/api/can-analyze` | BD-CAN 总线参数判定 |
| POST | `/api/chat` | 智能对话（`stream=true` 走 SSE 流式） |

### 3.1 POST /api/diagnose
```json
// 请求
{ "description": "车辆无法启动，仪表盘显示电池故障灯亮起",
  "vehicle": { "brand": "比亚迪汉EV", "year": "2023", "mileage": "2.6万公里" } }

// 响应
{ "ok": true, "faultType": "动力电池告警（BMS 报码）",
  "severityLevel": { "text": "高", "level": "high" },
  "possibleCauses": "绝缘电阻下降、单体过压/欠压、……",
  "systems": ["动力电池", "BMS", "高压安全"],
  "steps": [ { "title": "立即安全处置", "description": "…", "keyPoints": "…" } ],
  "suggestions": ["…"],
  "matched": true, "matchScore": 6, "knowledgeId": "battery-alarm",
  "source": "knowledge-base" }
```

### 3.2 POST /api/can-analyze
```json
// 请求
{ "resistance": 120, "can_h": 4.9, "can_l": 0.2 }

// 响应
{ "ok": true, "allOk": false,
  "items": [ { "name": "终端电阻", "value": 120.0, "unit": "Ω",
               "normal": "50 ~ 70Ω", "ok": false, "note": "…" } ],
  "conclusion": "BD-CAN 网络存在异常，建议按异常项逐条排查",
  "advice": ["先测量终端电阻：标准约 60Ω……"] }
```
判定标准：终端电阻 50–70Ω、CAN_H 2.5–4.5V、CAN_L 0.5–2.5V、压差 1.5–3.5V。

### 3.3 POST /api/chat
```json
// 请求
{ "message": "充电充不进去", "history": [ {"role":"user","content":"…"} ], "stream": true }
```
`stream: true` 时返回 SSE，事件序列：

```
data: {"type":"meta","mode":"local","model":null}
data: {"type":"delta","text":"【故障判断】充电系统故障"}
data: {"type":"delta","text":"…"}
data: {"type":"done","mode":"local","matched":"充电系统故障","elapsed":0.83}
```
可能出现的其它事件：`notice`（在线大模型失败并自动降级）、`error`。

`stream: false` 时直接返回 `{"ok":true,"reply":"…","mode":"local|llm"}`。

## 4. 双模运行

| 模式 | 触发条件 | 特点 |
|---|---|---|
| **离线知识库** | 默认；未填 API Key | 断网可用、响应 <1 秒、结果确定，适合比赛现场 |
| **在线大模型** | 在页面「设置」里填 Key 并勾选启用 | 回答更自然；调用失败会自动降级回离线并提示 |

**切换方法（推荐）**：页面「智能对话」→「设置」→ 填 Base URL / API Key / 模型名 → 「保存并测试」。
页面会显示当前模式与连通结果。

**兼容任何 OpenAI 格式接口**，例如：

| 服务 | Base URL | 模型示例 |
|---|---|---|
| 硅基流动 | `https://api.siliconflow.cn/v1` | `deepseek-ai/DeepSeek-V3` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 阿里百炼 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| 本地 Ollama | `http://127.0.0.1:11434/v1` | `qwen2.5:7b` |

也可直接改 `config.json`，或用环境变量临时覆盖：
```bat
set CHXZ_API_KEY=sk-xxxx
python server.py
```

> 在线模式下，服务端会先用内置知识库检索相关条目，作为"参考资料"一并注入提示词，
> 让大模型的回答更贴合实训场景。

## 6. 视觉主题与素材（v2）

整站为**暗色 HUD / 赛博工业风**，且**没有改动任何内容结构**（板块顺序、文案、尺寸关系全部保留）。

### 6.1 设计语言

| 维度 | 做法 |
|---|---|
| 几何 | 直角卡片 + 2px 切角，取代圆角玻璃卡；1px 发丝线取代泛光描边 |
| 构件 | 四角括号、边缘刻度尺、MODULE 编号、SN 序列号、幽灵大号编号、引线标注、跑马遥测 |
| 层级 | 辉光只给"热"元素（状态点 / 数据包 / 主按钮），其余靠线条精度和留白取胜 |
| 质感 | 胶片颗粒叠加（`noise.svg`，mix-blend-mode:overlay）+ 双色径向辉光 + 固定网格 |
| 色彩 | 冷青 `#35E0FF` 主强调、薄荷绿 `#7CFFB2` 次强调，警示 `#FFB020` / `#FF4D6D` 仅用于语义 |
| **故障** | 故障气质由**静态**元素承载：状态条、技术读数、序列号与模块编号、损坏字符点缀、极淡胶片颗粒。**不使用**横穿整屏的移动色带、全屏覆盖层或持续闪烁（2026-09-29 按用户要求收敛） |

### 6.2 动效与交互清单（`tools/cyber-fx.js`，零依赖）

**设计红线（2026-09-29 按用户要求收敛）**

> 不做**横穿整屏**、**持续闪烁**、**全屏覆盖**的效果。动效只能发生在
> ① 用户主动触发（悬停 / 点击 / 移动光标）或 ② 元素自身的局部小范围，
> 且必须可预期、可随时忽略。**故障气质改由静态排版承载**（技术读数、序列号、损坏字符点缀），
> 而不是靠动态覆盖层。
>
> 据此已移除：全局扫描亮带、两条全宽跟踪误差带、标题常驻通道分离、首屏面板常驻色差、
> 故障脉冲（整页错位 + 撕裂带 + 噪声爆发 + 坏点 + 扫描线加强）、信号丢失状态切换、
> 点击爆点、光标噪点故障场、光标拖尾撕裂、准星自身错位、跑马灯错位。

**页面动效**

| 动效 | 说明 |
|---|---|
| 首屏粒子场 | canvas 节点与连线，鼠标靠近时有斥力反馈（在背景层，不遮挡内容） |

| 滚动进度 | 顶部 2px 渐变进度条 |

**光标交互**（全部由光标移动或悬停触发，无自发闪烁）

## 8. 常见问题

**Q：页面显示「未连接后端（离线可用）」？**
后端没启动，或端口不是 8000。启动 `启动车小智服务.bat` 即可；用了别的端口时，
在页面加载前加一行 `<script>window.CHXZ_API_BASE='http://127.0.0.1:你的端口';</script>`。

**Q：填了 Key 但不生效、回答还是离线内容？**
① 检查「设置」里是否勾选了「启用在线大模型」；② 点「保存并测试」看返回信息；
③ 确认 Base URL 是否为 `/v1` 结尾（服务会自动补 `/chat/completions`）。

**Q：端口被占用？**
服务启动时会先探测该端口上是否已经跑着车小智：是则直接提示"已经在运行"并退出（避免同端口多实例）；
若被其它程序占用，会自动顺延到 8001~8010 并在控制台打印实际地址。
要指定端口：`python server.py --port 8010`，并按上面的方式把前端接口地址指过去。

> 为什么会做这个探测：Windows 的 `SO_REUSEADDR` 允许同一端口被多个进程重复绑定，
> 结果会出现"代码改了却不生效"——请求被随机路由到还在跑旧代码的实例。已实测踩过这个坑。

**Q：页面样式/图标丢失？**
页面通过 CDN 加载 Tailwind、Font Awesome、GSAP，断网时会退化成无样式。
如需完全离线，可把这三个库下载到 `车小智-后端/assets/vendor/` 并改写 `<head>` 里的引用。

**Q：数据会不会上传？**
默认只监听 `127.0.0.1`，仅本机可访问。只有在启用在线大模型时，对话内容才会发往你自己填的接口地址。
