# 新能源汽车智能检测系统 · 车小智

面向**新能源智能网联汽车**的离线检测诊断与车机数据可视化工具集。
纯前端单文件交付（零依赖、可离线运行），配套 Python 后端与 CAN / ROS 数据桥接。

---

## 内容

| 目录 / 文件 | 说明 |
|---|---|
| `车小智.html` | **车小智** —— AI 智能诊断专家页（单文件，约 1.2 MB，样式/图标/图表全部内联，断网可用） |
| `新能源汽车智能检测系统-1.0版.html` | **检测系统主看板**（单文件，同上） |
| `车小智-后端/` | `server.py`（本地 HTTP 服务 + 诊断接口）、`knowledge.py`（离线诊断知识库）、开机动画层 |
| `车机实时数据/` | CAN 桥接、ROS 桥接、数据探针，以及各层的幂等注入脚本 `apply_*.py` |
| `assets/` | 看板图标与装饰素材 |
| `检测系统-美化/` | 界面预览与样式附件 |

## 主要能力

- **智能诊断**：输入故障描述 → 给出「故障判断 → 分步排查 → 维修与安全建议」。内置 14 类新能源车故障的离线知识库，后端不可用时页面自动兜底，**全程无需联网**。
- **多模态输入**：诊断区与对话区均可附图（点选 / 拖拽 / 截图粘贴），图片随诊断记录留存与导出。
- **车机数据接入**：通过 CAN 桥接（USB-CAN 分析仪）与 ROS 桥接（车机 ROS Master）读取真实车辆数据，桥接不可用时界面自动降级为演示数据。
- **开机动画**：逐字渐显的授权序列 —— 硬切白闪覆盖黑幕切换、色散故障、冲击波、机位抖动、中央标识逐块拼装。支持 `?boot=0|1|auto`，`?boot=auto` 每会话重播一次。
- **桌面发布版**：PyInstaller 打包的免安装 exe，双击即用（见 Releases）。

## 环境

- 界面：Windows 10/11 + 系统自带 **Edge**（无需安装任何运行时）
- 后端 / 桥接：Python 3.12
- 车机侧：ROS（`roscore`，默认 `192.168.1.102:11311`）

## 快速开始

```bat
:: 1) 只用页面（不需要后端）
start "" "车小智.html"

:: 2) 起本地服务（可接在线大模型 / 图片导出）
python 车小智-后端\server.py

:: 3) 车机数据
python 车机实时数据\can_bridge.py --port 8780     :: 需要 USB-CAN 分析仪
python 车机实时数据\ros_bridge.py --port 8770     :: 需要连上车机网络
```

两个桥接都是**只读**的：只订阅、不发送。

## 说明

- 界面为**离线优先**设计：所有样式表、字体图标、图表库均内联在 HTML 内，不请求任何外部 CDN。
- 仓库**不含**构建产物、演示视频与比赛材料（体积原因），也不含任何 API Key（`config.json` 已在 `.gitignore` 中；需要联网大模型时按 `config.example.json` 自行填写）。
- 涉及**高压系统**的作业请交由具备资质的人员处理；本工具的结论仅供参考。
