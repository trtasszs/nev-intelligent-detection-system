面向**新能源智能网联汽车**的检测诊断与车机数据工具集，共四个软件：
**检测看板 · 车小智（AI 诊断）· 在环仿真测试平台 · 车机调试台**。
界面侧纯前端单文件交付（零依赖、可离线运行），配套 Python 后端、CAN / ROS 桥接与车机侧调试台。

### ① 车小智 — AI 智能诊断专家

输入故障描述 → 给出「**故障判断 → 分步排查 → 维修与安全建议**」。内置 14 类新能源车故障的离线知识库，后端不可用时页面自动兜底，**全程无需联网**。
支持多模态输入（点选 / 拖拽 / 截图粘贴），图片随诊断记录留存与导出。
开机动画：逐字渐显授权序列（硬切白闪、色散故障、冲击波、中央标识拼装），支持 `?boot=0|1|auto`。

### ② 新能源汽车智能检测系统 — 检测主看板

检测主界面；可叠加车机实时面板：**系统概览 / 车辆信息 / 检测记录 / 智能网联 / 通信协议 / 数据分析 / 系统设置** 共 7 个页面，
每个真实数据面板统一带 **`● LIVE`** 标记，演示数据保持原样、不贴标记。

### ③ 在环仿真测试平台

四模块（场景管理 / 仿真测试 / 数据分析 / 报告生成）；中栏三视图（场景俯视图 · 驾驶员前视 · 车辆在道路模拟）。
MIL / SIL 仿真内核：IDM 跟车模型 + 雷达 / 视觉双测量传感器模型 + 可解释风险评分 + L1–L4 分级；报告可打印导出。
顶部「模型在环 / 软件在环 / 硬件在环 / 整车在环」四个按钮即数据源开关，**页面内切换，不需要启动器**。

### ④ 车机调试台

运行在**车机侧 Ubuntu** 的图形调试台，按操作顺序分三个模块：
**MODULE 01 链路/启动 → 02 线控底盘 → 03 视觉/标定**；启动时做链路自检（车机可达性 + 宿主中继）。
详见 [`车机调试台/README.md`](车机调试台/README.md)。

## 主要能力

- **智能诊断**：故障描述 → 故障判断 → 分步排查 → 维修与安全建议；离线知识库，断网可用。
- **多模态输入**：诊断区与对话区均可附图（点选 / 拖拽 / 截图粘贴），随记录留存与导出。
- **车机数据接入**：CAN 桥接（USB-CAN 分析仪）+ ROS 桥接（车机 ROS Master）读取真实车辆数据；桥接不可用时界面自动降级为演示数据。
  - ROS 桥接订阅 **20 个话题**、对外提供 **7 个 HTTP 接口**；**自研 ROS1 动态解码**——靠发布方连接头里的 `message_definition` 解任意消息，**不需要装 ROS、不需要 VM 中转**。
  - 大消息（>12 KB，如点云 / 图像）只统计频率与字节数、不解码，避免拖垮桥接。
  - 两个桥接都是**只读**的：只订阅、不发送。
- **在环仿真**：MIL / SIL / HIL / VIL 四模式，页面内一键切换数据源；HIL 接车机 ROS 真实感知帧。
- **车机调试台**：线控底盘调控 + 多路视觉与融合标定 + 链路自检，见子目录 README。

## 环境

- 界面：Windows 10/11 + 系统自带 **Edge**（无需安装任何运行时）
- 后端 / 桥接：Python 3.12
- 车机侧：ROS 1（`roscore`，默认 `192.168.1.102:11311`）；车机调试台需 Python 2.7 + PyQt5 + OpenCV

## 快速开始

```bat
:: 1) 只用页面（不需要后端）
start "" "车小智.html"
start "" "新能源汽车智能检测系统-1.0版.html"
start "" "数字孪生测试代码.html"

:: 2) 起本地服务（可接在线大模型 / 图片导出）
python 车小智-后端\server.py

:: 3) 车机数据
python 车机实时数据\can_bridge.py --port 8780     :: 需要 USB-CAN 分析仪
python 车机实时数据\ros_bridge.py --port 8770     :: 需要连上车机网络
```

```bash
# 4) 车机侧调试台
bash 车机调试台/启动车机调试台.sh
```
